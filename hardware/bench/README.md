# 开放台架 · 可打印连杆

四根连杆依据 [5.2.2 几何中心距](../../firmware/JianClock/Geometry.h) 独立绘制，配合 [A4 台架模板](../bench-jig.svg) 使用。只需做一块开放底板，舵机槽、屏幕座和外壳可按手上的实物尺寸自行设计。

[整机打印包](../enclosure/README.md)包含以下同一套四件机械臂。没有打印机，也可按 [1:1 模板](../bench-jig.svg) 手工制作四根刚性件。

| 文件 | 用途 | 孔中心距 |
| --- | --- | --- |
| [`07-arm-left.stl`](../enclosure/stl/07-arm-left.stl) | 从正面看左侧舵机主动臂 L–E | 33.35 mm |
| [`08-arm-right.stl`](../enclosure/stl/08-arm-right.stl) | 右侧舵机主动臂 R–F | 34.85 mm |
| [`09-link-right.stl`](../enclosure/stl/09-link-right.stl) | 右侧随动杆 F–Q | 45.05 mm |
| [`10-link-lamp.stl`](../enclosure/stl/10-link-lamp.stl) | 三孔灯头连杆；最大孔 P 装灯 | E–P 53.85；E–Q 45.05；P–Q 13.00 mm |

1. 切片使用毫米、100% 比例，选择一件平放试打。模板厚 4 mm，关节通孔 3.2 mm，灯头通孔 5.2 mm。根据实际螺钉、灯珠外径和打印缩差试穿，再决定是否改孔；支撑、壁厚和材料强度以样件为准。
2. 两根主动臂轴端直径 16 mm 的圆端用于贴合自带舵盘。3.2 mm 孔只是通孔，不是 SG90 花键。以实际舵盘为基准完成防转固定和转印孔位；先做空载检查，确保螺钉不刮到舵机外壳。不要只靠轴心一颗松动螺丝传递扭矩。
3. 对 [台架模板](../bench-jig.svg) 安装。从正面看，按 E→P 方向观察时 Q 在其右侧；切片与装配均不要镜像。铰接处做错层和间隙，接灯前按[机械调试步骤](../README.md#3-装臂和校准)完成空走。

模型通过孔位、实体连通性和封闭网格检查。未打印、试装或测量关节间隙；不要把原机实拍当作这套台架的结果。

STL 的单位约定为毫米。需要修改孔径或厚度时，可把 STL 导入建模软件，以 A4 模板和上表的孔中心距为基准。
